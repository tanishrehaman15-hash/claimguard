## Description
ClaimGuard scores every insurance claim the instant it is filed, inside the transaction on IBM Z. Honest claims get paid in hours, and suspicious ones are held for an investigator, with clear reasons for every decision.

Running live on IBM LinuxONE (s390x): https://change-illustrations-tooth-complete.trycloudflare.com

- 99% of fraudulent payout value stopped before payout (time-based hold-out, synthetic data)
- 37% of claims fast-tracked with no manual work
- 81% vs 62% of fraud caught compared with red-flag rules at the same workload
- Identity graph exposes organised fraud rings
- Exact SHAP reason codes + IBM Granite investigator notes
- Human in the loop: no claim is ever rejected by a machine

Tech: Python, XGBoost, FastAPI, Streamlit, IBM LinuxONE, IBM Granite. Production path: Machine Learning for z/OS / Snap ML on the Telum on-chip AI accelerator.
